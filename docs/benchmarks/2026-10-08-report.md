# HelpDesk 초기 진단 30건 평가 — 2026-10-08

## 방법

- 11개 영역에서 서로 다른 가상 장애 패턴 30개를 선정했다. 각 질문은 실제 Jev → 로컬 검색 → 읽기 전용 도구 경로 → Qwen3 14B Q4 진단을 거쳤다.
- 첫 판단과 가상 참고 원인을 [원본 결과](2026-10-08-30-cases.jsonl)에 함께 기록했다. 평가용 카드는 `awaiting_review`로 남기고 참고 답안으로 자동 해결 처리하지 않았다.
- 질문과 검색 패턴이 **같은 가상 원천 데이터**에서 생성됐다. 이 평가는 초기 연결과 일관성을 확인하는 내부 표본이며, 실전 정확도나 일반화 성능을 측정하지 않는다.

원인 판정은 첫 판단 문장을 사람이 참고 원인과 대조한 **정성 분류**다. 부분 일치 6건은 `scenario-002`, `scenario-116`, `scenario-121`, `scenario-206`, `scenario-386`, `scenario-411`이다. 검색 상위 3건 포함률은 같은 원천 데이터로 만든 질문이므로 독립 검증 점수로 쓰지 않는다.

## 발견한 문제와 수정

1. LLM 콜드 스타트 연습 사례 `INC-1116`이 다른 영역 질문 27건 모두의 검색 상위 3건에 섞였다. 검색 문서에 영역을 보존하고 Jev의 주·보조 영역과 다른 가상/미검증 문서는 점수를 낮추도록 수정했다.
2. 마지막 3건에서 Qwen 응답을 얻지 못하자 일반적인 프런트엔드 문구가 OCR·프런트엔드 질문에 반복됐다. 가까운 가상 패턴이 있으면 **현재 원인 미확인**을 명시하고 읽기 전용 확인 절차만 제안하는 fallback을 추가했다.
3. 평가 작업이 두 차례 비정상 종료됐고 저장한 결과에서 재개했다. 종료 원인은 확정하지 않았다. 측정 당시 Mac의 메모리 여유는 낮았고, 14B Qwen 단계가 일부 질문에서 90초 이상 걸렸다. 모델 안정성과 처리량은 별도 실전 조건에서 다시 측정해야 한다.

이 변경은 Qwen 가중치 학습이 아니다. 실제 운영 사례 5건은 별도의 검증된 RAFT 데이터로 유지하고, 가상 패턴을 실제 해결 기록으로 승격하지 않는다.

수정된 검색기로 같은 30개 질문을 **검색만 다시 실행**한 결과, 무관한 `INC-1116`의 상위 3건 혼입은 **27 → 0건**이었고 기대 가상 패턴의 상위 3건 포함은 **30 → 30건**이었다. 이 재검사는 Qwen 답변을 다시 생성하지 않았으므로 답변 품질 개선 수치로 해석할 수 없다.
